# 跨环境复跑记录

- 复跑环境：队长本人 Windows 电脑（Python 3.9）与开发机 Linux 环境（Python 3.12）。
- 失败现象（Windows、Python 3.9、Hypothesis 6.141.1）：自测 4 条中
  `test_strategy_retry_on_bad_generator` 失败，报错 StopIteration；截图中可见
  校验信息 `InvalidArgument: 'generate' is not a valid phase`。
- 原因：生成器自校验调用 Hypothesis 设置时传了字符串 `"generate"`，
  新版接受、旧版只接受 `Phase` 枚举，导致第二个生成器也被误判、重试耗尽。
- 修复：`fanli/strategy.py` 改用 `Phase.generate`；同时把 `llm.chat` 调用
  移进异常处理，使调用失败时也能退回人工模板。
- 复跑结果：修复后在 Hypothesis 6.141.1 与 6.170.9 两套环境下各跑一遍，
  自测均为 4 条通过；第一题与第三题主程序在 Windows 机器上输出与预期全部一致。
